# Tổng quan API social

| Social                   | API chính                              | Chức năng                                                                                                |
| ------------------------ | -------------------------------------- | -------------------------------------------------------------------------------------------------------- |
| Facebook                 | Pages / Graph API + Messenger Platform | Đọc và quản lý bài Page, comment, Insights; đọc và trả lời tin nhắn, nhận tin mới qua webhook.           |
| Instagram                | Instagram API + Messaging              | Đọc/đăng media và Reels, quản lý comment, xem Insights; đọc và trả lời Direct, nhận tin mới qua webhook. |
| Facebook / Instagram Ads | Meta Marketing API                     | Đọc campaign, ad set, ad; phân tích chi tiêu, chuyển đổi, CPA, ROAS và breakdown.                        |
| Pinterest                | API v5                                 | Quản lý board và Pin, đọc nội dung, xem lượt hiển thị, lưu và click.                                     |
| YouTube                  | Data API + Analytics API               | Đọc/đăng video, đọc playlist và comment, xem thống kê kênh và hiệu suất video.                           |
| Telegram                 | Bot API                                | Thông báo tin nhắn khách mới, cấu hình nơi nhận theo Store.                                              |
